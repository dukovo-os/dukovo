# How long each boot test takes on one of CI's machines, in whole seconds:
# the time after PASS in the "./ob test boot --shard" steps' logs. CI runs
# the boot tests in several jobs at once, and `--shard` uses these times to
# give each job the same amount of work, so that no job ends long after the
# others. A test that is not here counts as 40 seconds, about the average,
# so a new test needs no line until it turns out to be much slower or
# faster than that; a line must name a test that exists (a unit test checks).
#
# Rough is fine: the times change from run to run by about 10 percent.
# Measured 2026-11-06 on main and pull request runs.
