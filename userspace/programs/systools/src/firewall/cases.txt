# Which rule of the firewall's settings decides a connection, a datagram
# or a ping that another machine starts (firewall(8)): the Firewall page's
# model (rules-model.js), which asks whether a change cuts the browser
# off, and firewall.rs's `decides` both read this file in their tests, so
# that the page and `firewall test` say the same.
#
# A case is a block of lines, the blocks apart by a blank line: the rules,
# a line each as the settings file has them, then one or more questions.
# A question is a line that starts with `> `: the protocol (tcp, udp or
# ping), the port (not for a ping), `from ADDRESS`, `on CARD`, and
# `program PATH` when the program that listens is known; then ` => ` and
# the rule that decides, its number from 1 and allow or deny, or `none`
# when no rule does. The first rule that fits decides. A block with no
# rules starts with its questions.
