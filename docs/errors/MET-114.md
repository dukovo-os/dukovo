# MET-114: A RAID controller is in fault

A RAID controller reports a fault: its firmware stopped with an error. metricsd raises a critical alert, key `raid-controller:CONTROLLER`, and the title gives the model and the firmware's fault code. The disks behind the controller cannot be used until it works again. The alert is cleared when the controller's state is operational.

This is the same fact as the failure of `hardware check raid` (HW-175), told when it happens and not when someone looks.

## What to do

1. Run `storage raid events` to see what the controller logged.
2. Restart the machine, and follow HW-175: update the controller's firmware if it faults again, and contact its maker with the code.
3. To check that it worked, run `storage raid` and see the controller working normally.
