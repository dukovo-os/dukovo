# NET-183: SSH's settings file has a mistake

`ssh-server set` was run, and the settings file, `/system/settings/ssh/sshd_config`, has a line that sshd(8) does not read: an unknown keyword, a value out of range, or a keyword with none. Editing it would carry the mistake on, and sshd reads the same file when it starts, so the command refuses and writes nothing. `ssh-server show` lists each mistake with its line and why. Nothing was changed.

## What to do

1. Run `ssh-server show` to see which lines are wrong, and what each says.
2. Correct or remove them in `/system/settings/ssh/sshd_config`, as an administrator, or put back an earlier version of the file from the What changed page.
3. Run the command again.

## See also

ssh-server(8), sshd_config(5), sshd(8), the handbook's chapter on the web console.
