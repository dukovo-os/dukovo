# HW-152: A network link is at half duplex

A network card negotiated half duplex with the device at the other end of its cable, so it cannot send and receive at the same time, and collisions slow it down. Modern networks run at full duplex. A link at half duplex is nearly always a cable or a switch port in trouble: when two ends cannot agree, or one is set by hand to a fixed setting and the other is not, they fall back to it.

## What to do

1. Run `nic CARD` to see the card's speed and duplex. A speed of 10 or 100 Mb/s on a gigabit card goes with half duplex: the cable is the likely fault.
2. Replace the cable with one that is known to be good, and plug it into another port of the switch.
3. If the switch's port is set by hand to a speed and duplex, set it to negotiate, or set the card to match.
4. To check that it worked, run `elevate hardware check network` and see the link at full duplex.
