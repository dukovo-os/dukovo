# ADM-133: This connection was opened before the change

The page asked whether this browser still reaches the console over the settings that were just put to use, and the question came by a connection that was opened before the change took effect. A firewall rule is checked when a connection begins, and a connection that is open goes on, so an answer over it would prove nothing about the new settings. The console ends the connection after this answer, so that the browser's next request opens a new one. Nothing was changed.

## What to do

1. Nothing needs fixing: the page asks again by itself, over a new connection, and turns on **Keep this change** when one gets through.
2. If the page goes on saying that it cannot tell, reload it, or open the console in a new tab, which opens new connections.
3. If no new connection gets through, the change cuts this browser off. It is undone at the time the page shows, unless it is kept; at the machine, `elevate network undo` or `elevate firewall undo` undoes it at once.
