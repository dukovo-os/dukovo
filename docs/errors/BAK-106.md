# BAK-106: A file is already there by that name

`snap restore --beside` was asked to put a copy of a file from a snapshot beside the file, under a name made from the label, and a file or folder has that name already. A restore never writes over what is there, so the file you have now and the copy you asked for both stay. Nothing was changed.

## What to do

1. Look at the file the message names. If it is a copy from an earlier restore with the same label, it may be the one you wanted.
2. To make another copy, run the restore again with a different label.
3. To replace the copy, move it away or delete it first, then run the restore again.

snap(1), the handbook's chapter on the web console.
