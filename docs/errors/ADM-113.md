# ADM-113: That is too big

A request or an answer is longer than the console takes. A request's body is at most 64 KiB before sign-in and 1 MiB after. Between the server and a session's worker, nothing is longer than 4 MiB. The console's own pages send a few hundred bytes. The detail says how much a body may hold here.

## What to do

1. Send less. A script that makes this by posting a large body has to cut it.
2. If the console's own page gets this, reload it, and report it with the detail.
