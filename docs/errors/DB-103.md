# DB-103: The database has open sessions

PostgreSQL does not drop a database while a program is connected to it. `database remove` says how many sessions are open and which programs they belong to, by the `application_name` each gave when it connected, so that you know what to stop. Nothing was removed.

## What to do

1. Stop the programs the line names, or the website that uses the database, then run `database remove` again.
2. To remove it with the sessions open, add `--force`: PostgreSQL ends them, and what they were doing is lost. Use it only when you know the programs can be lost.
3. To check that it worked, run `elevate database list`: the database is no longer in it.

database(8), the handbook's chapter on PostgreSQL, DB-102.
