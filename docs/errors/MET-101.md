# MET-101: A filesystem is nearly full

metricsd warns when a filesystem is 90 percent full, or the percent that `filesystem` in metrics.toml says, and the warning is critical from 97 percent. The message names the folder it is mounted at, how much is in use and its size. The warning is cleared when the use falls 3 percent below the line. A filesystem mounted read-only is not checked.

A full filesystem refuses new files, and a program that cannot write fails in ways that are hard to trace, so act before it is full.

## What to do

1. Run `df -h` with the folder the message names to see what is in use and what is free.
2. Delete what is not needed there: old downloads, copies, and the snapshots that hold files you have deleted since (`subvolume delete` removes a snapshot; the handbook's chapter on updates, snapshots and backups says which are safe to remove).
3. If the filesystem is a disk that has room to grow, or the files can move to another disk, do that.
4. Check that it worked: `metrics fs.used` shows the use at the next minute, and the warning is cleared when it is below the line less 3 percent.

To warn earlier or later, change `filesystem` in /system/settings/metrics.toml and run `service metricsd reload`.
