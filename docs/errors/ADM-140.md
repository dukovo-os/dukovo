# ADM-140: The one-time link was used or has ended

The address was a one-time link to the text of a report: the Report a problem page shows it as a QR code, so that a phone can download the report. A link works once, for 10 minutes. This one was opened already (a program that only looks at a link, as a chat program does to show a preview, opens it too), or its 10 minutes have passed, or the console restarted, which forgets every link it made, or the address is not one the console made. The phone shows these words in place of the report. The report was not changed.

## What to do

1. If the phone has the file, nothing needs fixing: a link is for one download.
2. To make another, choose **Download by QR code…** on the Report a problem page again. It draws a new link and code, good for one download in 10 minutes. If the page says that the draft has ended (RPT-101), draft the report again first.
3. The phone warns of the console's certificate. Compare the fingerprint the page shows with the one the phone shows, and go on if they are the same.
4. If the link was used and you did not use it, someone else had its address. They got the text the page showed, in which names and addresses were taken out already. Send a link to no one: it is for the phone you hold.
5. To keep the report without a phone, choose **Save to a file…** on the page.
