# NET-111: The network card has no address

The card has a link, but no address to send from. The message says why: either DHCP got no answer, or the card's settings in /system/settings/network give it no address and say not to ask DHCP.

## What to do

If the message says DHCP got no answer:

1. Check that a DHCP server is on this network. A router gives addresses unless it was set not to.
2. Run `log -s netd` to see what the card asked and what came back.
3. If the network has no DHCP server, give the card an address of its own in /system/settings/network, as the handbook's chapter "Networking" shows, and run `service netd reload`.

If the message says the settings give no address:

1. Read /system/settings/network, whose section for the card (`[net0]`) names `address =` and `router =`, or `dhcp = yes`. A card with `dhcp = no` and no address is left alone.
2. Give it an address, or set `dhcp = yes`, and run `service netd reload`.
3. Run `netcheck` again: it passes the address layer once the card has an address.

## See also

netcheck(8), netd(8), network(5), log(1), ip(8), the handbook's chapters "Networking" and "Checking the network".
