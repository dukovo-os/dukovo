# BAK-104: A whole-machine restore is staged already

`backup restore --machine` was run while a restore of a whole machine is staged for the next start. The first is carried out when the machine starts, and a second would replace it before the person has seen it done. Nothing was changed.

## What to do

1. To carry out the staged restore, restart the machine.
2. To give it up, run `elevate backup restore --machine --cancel`, or choose Cancel on the Move page. The machine is left as it is.
3. After a cancel, stage the restore again with the choices you want.

## See also

backup(8), the handbook's chapter on moving to new hardware.
