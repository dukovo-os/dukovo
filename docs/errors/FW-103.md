# FW-103: The CPU microcode did not reach the kernel

The slot names a firmware set with CPU microcode, but the kernel received none: GRUB did not load it from the root's firmware store. During the set's first start, the firmware update fails and the computer goes back to the set before it by itself.

## What to do

1. Run `sysupdate firmware` to see the sets each slot names and whether the store holds them.
2. Stage the set again with `sysupdate firmware stage`.
3. If GRUB was changed by hand, put it back with Rescue.

## See also

sysupdate(8), radix-sysfs(5).
