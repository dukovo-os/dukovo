# HW-104: The memory test at the start did not finish

A memory test was asked for the start, with `hardware memtest --next-start` or the Hardware page, and the start menu took it, but the test never told the system that it was over. The power went, the machine stopped, or it was restarted by hand while the test ran. Memory that is failing can make a machine stop, so this is a reason to look at the memory again, though it is not proof.

The test is asked for once. The next start was the usual one, and nothing is asked now.

## What to do

1. Run `hardware memtest --status` to see what the last test that did finish found, and when.
2. If the power went, or someone restarted the machine, ask for the test again with `elevate hardware memtest --next-start`, and leave the machine alone until the system is back. The test takes about 4 minutes for each 16 GiB of memory, and stops after an hour.
3. If the machine stopped by itself while the test ran, and does so each time, the memory is likely faulty. Take out all but one module, and test each in turn; the one that stops the machine is the one to replace.
4. To check that it worked, run `hardware memtest --status` after a start that tested all the memory: the last test must say it passed.
