# WEB-105: nginx or PHP-FPM is not installed

A website is served by nginx, and a PHP site also needs PHP-FPM, which runs its PHP. `website add` checks bundled's record that each is installed for everyone, and the line says which is not. Nothing was changed.

## What to do

1. Install it for everyone. In the web console, the Add a website page offers the install as its first step. At a terminal: `elevate bundle install org.nginx.nginx --for-everyone` for nginx, and `elevate bundle install net.php.php --for-everyone` for PHP-FPM. Each shows its sheet first and asks.
2. `bundle list` shows what is installed. An app installed for yourself only is not enough: the services of a bundle run for everyone.
3. To check that it worked, run `website list`: its `nginx` and `php_fpm` say that each is installed. Then run the command that stopped again.
