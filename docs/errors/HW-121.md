# HW-121: The kernel logged corrected machine-check errors

The processor's machine-check banks reported errors that the hardware corrected, and the kernel's log holds them (lines that begin `Machine check: CPU`). The log is read before and after the load of the check, and the line says how many are in it since the start and how many came during the check. Corrected errors lose nothing. Many come from the processor's caches, its memory controller or the link between them, and a number that rises is a sign of heat, of a setting that is too fast for the part, or of a part that is wearing out.

## What to do

1. Run `elevate dmesg | grep "Machine check"` to see them: each line names the CPU, the bank and what it found. A memory error names a channel, which says which module.
2. Check the processor's cooling: that the fans turn, the vents are clear and the cooler is seated and has paste. Run `elevate hardware check cpu` and see if the temperature line is near its limit.
3. Undo any overclock or undervolt, and set the memory to its default speed.
4. If the count keeps rising after a restart with default settings, plan to replace the part that the lines name.
5. To check that it worked, restart and run `elevate hardware check cpu`: the machine checks line must say `none in the kernel's log since the start`.
