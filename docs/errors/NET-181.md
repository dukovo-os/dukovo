# NET-181: There is no such network card

`network show` or `network set` was given the name of a card, or a MAC address, that this machine does not have. A card is found by its name, such as `net0`, or by its MAC address, in the same letters or in capitals. A card that is unplugged or not in use is still a card; a card that the machine does not know has no name. Nothing was changed.

## What to do

1. Run `network show` to list the cards the machine has, with their names and MAC addresses.
2. Run the command again with a name or a MAC address from that list.

network(8), network(5), ip(8), the handbook's chapter on the web console.
