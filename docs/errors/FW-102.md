# FW-102: The processor refused the CPU microcode

The processor did not take the microcode update the firmware set holds: the message gives the revision it asked for and the one it runs. During the set's first start, the firmware update fails and the computer goes back to the set before it by itself.

## What to do

1. Check that the set is meant for this processor: `lscpu` names it.
2. Some processors take an update only after a firmware (BIOS or UEFI) update from the computer's maker; install that first.
3. Otherwise keep the set before it, and report the processor and both revisions.

## See also

sysupdate(8), lscpu(1), radix-sysfs(5).
