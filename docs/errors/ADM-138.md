# ADM-138: Who may reach the console is being tried

`admin reach` or `admin sign-in` was run while a change of the console's settings is being tried. Both write `/system/settings/admin.toml`, which Spark keeps in the trial `console` and undoes by putting the file back as it was before the trial, so a second change made now would be lost when the first is undone. Nothing was changed.

## What to do

1. Keep the change being tried with `elevate admin keep`, or undo it with `elevate admin undo`. The Security page shows the same trial with **Keep this change** and **Undo now**.
2. Or wait: Spark undoes the trial when its time runs out, and the page or `service list --json` says when.
3. Make the new change again.
