# NET-185: A device already has that name

`wireguard add` was given a name that another device of private access has. A device is told apart by its name in the list, and in the file that holds the interface's peers, so two with one name could not be removed one at a time. Nothing was changed.

## What to do

1. Run `wireguard show` to see the names that are taken.
2. Run the command again with another name, such as the person's and the device: `ann-phone`.
3. If the device is the same one, and its file was lost, remove it with `wireguard remove` and add it again: its private key is made once and is not kept on the machine.
