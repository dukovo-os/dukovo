# HW-161: The hardware reported an error that was not corrected

The kernel heard of a hardware error that the hardware could not correct, since the machine started, or the firmware recorded one from before this start. The report comes from a processor's machine-check bank, from the firmware's own error sources, or from a PCIe device. A recoverable error is one that the machine went on after, and a fatal one is one that it could not. The firmware's record from before this start (the BERT) is the error that ended the last run, such as a crash or a sudden restart, and is shown as an error even when it was corrected.

The kernel keeps the last 256 errors in `/kernel/ras/errors` and the counts in `/kernel/ras/counts`, and anyone may read both.

## What to do

1. Run `hardware errors` to see which part reported it. The part is a memory device, a PCIe device or a processor bank, and the line says what it was.
2. Back up what matters now. Data that was in the part when it failed may be wrong.
3. If the part is a memory device, restart the machine and choose *Test the memory* in the start menu, then replace the module that the errors name if it reports again.
4. If the part is a PCIe device, reseat the card, try another slot and update its firmware. Replace it if it reports again.
5. To check that it worked, restart the machine and run `elevate hardware check errors` after a day of use. The record starts empty at each start.
