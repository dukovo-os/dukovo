# ADM-125: A value cannot work

One of the values given to an action is of the right kind but cannot work, such as a port of 70000 or a name that starts with `-`. The answer's `field` names it, and the console's page shows the detail under that field. Nothing was run.

## What to do

1. Read the detail: it says what the value may be.
2. Change the value, then try again.

## See also

admind(8), dukovo-admin(7), ADM-108, the handbook's chapter on the web console.
