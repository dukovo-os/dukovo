# ADM-105: Too many tries: wait a moment

The console has had as many sign-in requests as it takes from this address in a minute: ten, counting each password, code and passkey request. It answers without asking authd, and the answer says in `Retry-After` how many seconds to wait. The detail is "too many sign-in requests from this address". The same ID also appears for a session's worker that has as many calls as it takes at once, 16.

This is a limit of its own, apart from the wait that authd puts on a wrong password or code, which makes the page slow to answer with ADM-101 or ADM-102. People who share one address, as they do behind one router, share the count.

## What to do

1. Wait for the number of seconds the page gives, then try once.
2. A script that signs in over and over has to slow down.
3. For a worker with too many calls, wait a few seconds and try again.
