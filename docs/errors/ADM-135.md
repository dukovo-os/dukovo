# ADM-135: Nothing is being tried by that name

The page asked whether this browser reaches the console over the settings of a trial, `network` or `firewall`, and Spark lists no such trial. It was kept, undone or ended already: a trial is undone by Spark when its time runs out, and also when the machine starts again while it runs. Nothing was changed.

## What to do

1. Open the Networking or Firewall page: it shows whether the change is in force, and a change that Spark undid has a row in the list of changes saying so.
2. At a terminal, `service list --json` prints the trials Spark keeps, with the time each has left, and the last undone ones.
3. To make the change again, start it again from its page.
