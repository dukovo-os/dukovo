# MET-109: The hardware reported an error that was not corrected

The kernel recorded a hardware error that the hardware could not correct (recoverable or fatal), or the firmware recorded an error from before this start. metricsd raises a critical alert for each one, once, with the key `ras:` and the error's number in the kernel's record. The title names the part and says what it was. A restart of metricsd does not alert again for an error it had; a restart of the machine numbers the errors from 1 again.

This is the same fact as the failure of `hardware check errors` (HW-161), told when it happens and not when someone looks.

## What to do

1. Run `hardware errors` to see the error and the others the kernel heard of.
2. Back up what matters, then follow HW-161: test the memory if the part is a memory device, and reseat or replace a PCIe device.
3. To check that it worked, restart the machine. The alert is cleared when metricsd or the machine starts again, and a part that is still failing reports again.
