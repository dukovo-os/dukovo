# ADM-131: There is no such terminal

The terminal or pane the request named is not one of this account's. It may have ended: a shell that exits ends its pane, and the console ends every terminal when it restarts. The same answer comes for a terminal of another account, so the console never says whether another account's terminal is there. Nothing was changed.

## What to do

1. Open the Terminal's Sessions page, which lists this account's terminals as they are now, and open one from there.
2. If every terminal is gone at once, the console restarted: start a new terminal. Work that must outlive the console belongs in a service, or in a program run with `nohup`.
