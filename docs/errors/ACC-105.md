# ACC-105: An account already has that name

`user add` or `user rename` was given a name that another account has already. Names are never shared, and the name of a removed account is not given again to its files: the account's number is kept for it. Nothing was changed.

## What to do

1. Run `user list` to see the names that are taken.
2. Run the command again with another name.
3. If the name is that of an account that should not be there, remove it first with `user remove`, and say what becomes of its home.

## See also

user(8), the handbook's chapter on the web console.
