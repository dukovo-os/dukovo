# ADM-145: There is no such request

An AI client's request for a change was approved, refused or looked up, and the console has no request with that number. A request waits for an administrator's yes for an hour and then lapses. Requests that wait are kept in the console's memory, so a restart of the console ends them too, and the page's list of what the clients did then shows them as lapsed. A request that was approved or refused already is not waiting any more. An AI client sees only its own requests.

Nothing was changed.

## What to do

1. Reload the AI clients page: it shows the requests that wait now, and under "What they did" what came of the others.
2. If the change is still wanted, have the AI client ask again. It gets a new number.
