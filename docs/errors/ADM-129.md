# ADM-129: This server does not have that command yet

The console knows the action, and the program that does it is not on this machine. The console runs each action as a command, and finds the program only in `/system/commands` and `/applications/commands`; the detail names the program it looked for. This happens when the console's pages come with a part of Dukovo that a later update brings, such as `dukovo-check` for the Overview's health score. Nothing was run.

The page shows this in place, as a part of the server that is not there yet, not as a fault.

## What to do

1. Nothing needs fixing: the action works once an update brings its program. `update check` says whether one is waiting.
2. If the program was there before, it may have been removed by hand or with its bundle: `bundle list` shows the bundles installed, and `bundle install NAME` puts one back.
