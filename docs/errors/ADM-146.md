# ADM-146: Too many requests wait for a yes

An AI client asked for a change, and as many requests wait for an administrator's answer as the console keeps: 8 for one client, and 64 for all of them. The limit keeps the list on the AI clients page one that a person can read, and keeps a client that asks in a loop from burying what the others asked for. Nothing was changed, and the request was not kept.

## What to do

1. On the AI clients page, approve or refuse the requests that wait. A request that nobody answers lapses after an hour.
2. Have the AI client ask again then. The answer says after how many seconds a request can lapse at the soonest.
3. If one client fills the list again and again, remove it: `admin mcp remove NAME`, or Remove on the page.
