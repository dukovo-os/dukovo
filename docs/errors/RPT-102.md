# RPT-102: The report is not the one you read

reportd sends only the text it drafted, and only when the SHA-256 that comes with the request is that text's. The draft is kept, but the hash given is another's: the text that was read is not the text reportd holds. The report is what its sender read and agreed to, so reportd refuses to send anything else. Nothing was sent, and the draft is kept until it ends.

## What to do

1. Draft the report again from the Report a problem page, read the text it shows, and send that.
2. If it happens again with no change of yours, do not send it: save the text with **Save to a file…**, and send it from another machine or by `report` at a terminal, which shows the text it sends.
