# ACC-102: That would leave no administrator

authd refused to disable or remove an account, or to take the administrator right from it, because it is the last enabled account in the `admins` group. With none, no one could run a command as an administrator, make another administrator, or make changes in the console, and Rescue and recovery need one. The rule holds at a terminal, with `elevate user ...`, as it does from the console. Nothing was changed.

## What to do

1. Make another administrator first: `elevate user set --admin NAME` for an account that is enabled, or `elevate user add --admin NAME` for a new one.
2. Then run the command again.
3. If every administrator account is lost, restart into the startup-trouble menu, which resets an administrator's password.

user(8), authd(8), ADM-136, the handbook's chapter on the web console.
