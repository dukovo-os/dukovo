# ACC-104: The account has no such key, token or session

`user key remove`, `user token remove` or `user end` named a key by its fingerprint, a token by its name, or a session by its number, and the account has none of that name. It may have been removed already, a token may have run out and been taken away, or the session may have ended: a session's number is its first process and the time it started, so a number that was used again by another process is not the session that was meant. Nothing was changed.

## What to do

1. Run `user show NAME` to list the keys, tokens and sessions the account has now, with the name each is given by.
2. Run the command again with one from that list.
3. If what you meant to remove is not there, there is nothing more to do.

user(8), the handbook's chapter on the web console.
