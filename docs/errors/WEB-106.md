# WEB-106: The certificate does not name every name of the site

An HTTPS site names its certificate, and a browser that opens the site under a name the certificate does not cover shows a warning. `website add` and `website https` check, before they change anything, that certd has the certificate and that its names cover every name of the site, `www.` ones included. The line names the names it lacks. Nothing was changed.

## What to do

1. Run `cert list`: it shows each certificate and the names it covers. `cert show NAME` shows one.
2. Use a certificate that covers every name: `elevate cert get NAME --name OTHER` orders one from Let's Encrypt for the site's name and the others, or a certificate you added with `elevate cert add` that does. This machine's own certificate, `this-machine`, covers the machine's own names only.
3. Or leave out the names the certificate does not cover: give the site fewer `--name` options.
4. To check that it worked, run the command that stopped again, with the certificate that covers every name.

website(8), cert(8), the handbook's chapter on certificates, WEB-103.
