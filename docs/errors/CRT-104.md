# CRT-104: An IPv6 address of the name leads elsewhere (a warning)

The name has an AAAA record, and none of its addresses is this machine's. Either this machine has no IPv6 address on the internet at all, or it has some and the record names others, such as another machine's. The authority tries IPv6 first, so it would connect to that address and look for the answer on whatever is there, and the order would fail with a message that does not say why. This is a warning, not a failure: the check cannot tell an address of another machine from one that reaches this machine another way, through a router or a tunnel.

## What to do

1. Read the line: it names the name, its AAAA address, and this machine's own IPv6 addresses if it has any.
2. If the record is not this machine's, remove the AAAA record at your DNS provider, or point it at the address the line says this machine has. If this machine has no IPv6 address, remove the record.
3. If the address is this machine's behind a router or a tunnel that the check cannot see, leave it and go on; `elevate cert get NAME --dry-run` asks the staging authority to try for real and installs nothing.
4. To check that it worked, run `elevate cert get NAME --check`: the line passes without the warning.
