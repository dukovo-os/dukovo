# HW-162: A memory device corrected many errors in a day

One memory device had 24 corrected errors or more in the last 24 hours. The memory has error correction, which made each error right before any program saw it, so nothing was lost. A single corrected error is not a fault. A device that needs correcting many times a day is often starting to fail, and one that fails further gives errors that cannot be corrected.

The count is made from the times in the kernel's record (`/kernel/ras/errors`). When the record has dropped its oldest lines, the count of the device since the start, scaled to a day, stands in for it, and the line says so.

## What to do

1. Run `hardware errors` to see the device. Its place on the board, such as `DIMM_A1`, is named with its count.
2. Restart the machine and choose *Test the memory* in the start menu. It tests all of the memory, which `hardware check` cannot do while the system runs.
3. Take the module out and put it back, and clean its contacts. A module that sits badly gives errors that stop when it is seated.
4. If the errors come back at the same device, replace the module.
5. To check that it worked, run `elevate hardware check errors` after a day and see a count under 24 for each device.
