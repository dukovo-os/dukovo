# ADM-128: That cannot be done to this one

What was asked cannot be done to this change or task as it is. The detail says which of these it is:

- Keep it is for a change made by hand: a change made through the console is kept already, and a change someone marked seen stays as it is.
- Put back needs the earlier text of every file the change names. A file the change made has no earlier text to write back. A secret, or a file that not everyone may read, is never kept. A file longer than 1 MiB, or one of the versions older than the last 20 of its file, has no text kept either.
- A task that ended cannot be stopped.

Nothing was changed.

## What to do

1. Read the detail.
2. For a change that cannot be put back, make the earlier setting again by hand, or with the page for it, knowing what it was from the change's diff.
3. For a task that ended, read its log: it says how it ended.
