# NET-182: SSH's settings are being tried

An `ssh-server` command that changes SSH's settings, or turns SSH on or off, was run while an earlier change to them is still being tried. Spark keeps one trial for a file at a time and undoes it by putting the files back as they were before the trial, so a second change made now would be lost when the first is undone. Nothing was changed.

## What to do

1. Keep the change being tried with `elevate ssh-server keep`, or undo it with `elevate ssh-server undo`. The Security page shows the same trial with **Keep this change** and **Undo now**.
2. Or wait: Spark undoes the trial when its time runs out, and the page or `service list --json` says when.
3. Make the new change again.
