# BAK-105: There is no such snapshot

`snap browse` or `snap restore --from` was given the name of a snapshot that the place does not have. A snapshot is named when it is made, by `snap create` or by the timer, and a snapshot that the keeping rules have removed is gone. Nothing was changed.

## What to do

1. Run `snap list PLACE` to see the snapshots the place has now, with their names.
2. Run the command again with a name from that list.
3. If the snapshot you want was removed, `backup restore` brings back files from a backup place, when the machine has one.

## See also

snap(1), snap.toml(5), backup(8), the handbook's chapter on the web console.
