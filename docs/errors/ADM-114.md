# ADM-114: This is not the name of this machine

The request's `Host`, the name or the address the browser opened, is not one this machine answers to. The console answers only to the machine's name, that name with `.local`, `localhost`, the addresses of its cards, and the names of the certificate it serves, so that no other name's DNS can point a browser at it. Any port is answered, so a router's port forward or an SSH tunnel works. It appears when the console is opened through a name that is not one of those, as a public name pointed at a home address does, or through a proxy that sends its own name.

## What to do

1. Open the console by a name or an address from the machine's own sign-in screen, such as `https://duke-nas.local:9090`.
2. To open it by another name, get a certificate for that name (`elevate cert get`), name the certificate as `certificate` in `/system/settings/admin.toml` and in `certificates` of admind's service file (`elevate service edit admind`), and reload admind (`elevate service admind reload`).
3. A proxy has to send the `Host` that the browser asked for.
