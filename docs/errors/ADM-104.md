# ADM-104: This account may not use the console

The password is right, but the account is not one that signs in to the console. It is told so only to someone who gave the right password, so that a wrong guess learns nothing about which accounts exist. The detail says why:

- The account is root's. Root never signs in to the console: an administrator does, and makes changes there once the console is unlocked.
- The account is disabled.
- The account is neither an administrator's nor a member of the group `console`.

An account that loses its right while it is signed in has its sessions ended, which the page shows as ADM-107.

## What to do

1. Sign in as an administrator instead, if the account is root's.
2. For a disabled account, an administrator enables it: `elevate user enable NAME`.
3. To let a person in who is not an administrator, an administrator runs `elevate user set --console NAME`, and `elevate user set --no-console NAME` takes it away. `elevate user list` shows who is an administrator.
4. The person signs in again.
