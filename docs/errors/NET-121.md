# NET-121: The network card has no default route

The card has a link and an address, but no router to send what is not on its own network to. It can reach the machines on its network and nothing beyond.

## What to do

1. Run `ip route` to see the routes the machine has. A default route reads `default via 192.168.1.1 dev net0`.
2. If the card asks DHCP, the DHCP server gives the router: check that the router is set to give one, and run `log -s netd` to see what it gave.
3. If the card has an address of its own, name the router with `router =` in the card's section of /system/settings/network, and run `service netd reload`. The router must be on the network of one of the card's addresses.
4. Run `netcheck` again: it passes the gateway layer once the router answers.

## See also

netcheck(8), netd(8), network(5), ip(8), the handbook's chapters "Networking" and "Checking the network".
