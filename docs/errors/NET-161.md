# NET-161: Packets of the card's full size do not get through

This is a warning. The gateway answers a small echo request, but not one as large as the card's MTU lets through, 1500 bytes on most networks. Small exchanges such as DNS work, while larger ones, such as loading a page or an update, stall or time out.

The cause is usually a device between this machine and the gateway that carries smaller packets than the card sends: a tunnel, a switch that has been set to a smaller size, or a router that drops large packets without saying so.

## What to do

1. Run `ping -s` with a size and the gateway's address, to find the largest packet that goes through: the size is the data bytes, and the headers add 28 for IPv4 and 48 for IPv6.
2. Ask whoever runs the network to allow the card's size between this machine and the router.
3. Or set the card's MTU to the size that goes through with `ip link set net0 mtu 1400`, until the network is fixed.
4. Run `netcheck` again.

## See also

netcheck(8), ping(8), ip(8), the handbook's chapters "Networking" and "Checking the network".
