# ADM-101: The name or the password is wrong

The console asked authd to check a name and a password, and authd says that they do not go together. The message does not say which of the two is wrong, or whether the account is there, so that no one can use it to find out who has an account. It appears on the sign-in page, and again when the password is asked for to unlock the console or to change a second step, if what was typed is wrong.

A wrong password is answered only after a wait: 2 seconds for each of the first three in a row, then twice as long each time, up to a minute. The wait is counted for each account from each address of a browser, so the page may take a while to answer, and trying again at once only makes the next wait longer. A right password ends the run, and so do 15 minutes with no try.

## What to do

1. Check the name. It is the one used at the machine's own console and over SSH: lower-case letters, digits, `_`, `-` and `.`.
2. Check the password, and that Caps Lock is off. It is the same password as at the console and over SSH.
3. Wait for the answer before trying again.
4. If the password is forgotten, an administrator sets a new one: `elevate passwd NAME`.

An account that may not use the console is told so only after the right password: see ADM-104.
