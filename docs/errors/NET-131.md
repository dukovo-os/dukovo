# NET-131: resolved has no DNS server

Names cannot be looked up: resolved's settings name no DNS server, and DHCP, DHCPv6 and the routers' advertisements gave none. Programs can still use addresses, but not names.

## What to do

1. Run `resolvectl status` to see the servers resolved asks, and where each came from.
2. If the card asks DHCP, check that the DHCP server gives DNS servers; a router gives itself unless it was set otherwise. Run `log -s netd` to see what it gave.
3. Otherwise name a server with `servers =` in /system/settings/resolved, such as the router's address, and run `service resolved reload`. A card's own `dns =` in /system/settings/network names a server for that card too.
4. Run `netcheck` again: it passes the DNS layer once a server answers.
