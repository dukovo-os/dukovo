# HW-172: A disk behind a RAID controller has failed

The controller has given up a disk: its state is *failed*, or *bad* when the disk is not in use. The line names the disk by its bay and gives its model and serial number, which is what to look for on the label. A volume that was using it is degraded (HW-171) until it is rebuilt on a replacement.

## What to do

1. Run `storage raid` to see the bay, and `storage raid events` to see what the controller logged when the disk went.
2. Replace the disk in that bay with one at least as large. If the controller has a hot spare, it has probably started the rebuild already.
3. Run `storage raid` again to follow the rebuild.
4. To check that it worked, run `elevate hardware check raid` and see no disk reported.
