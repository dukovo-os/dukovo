# RPT-101: That draft has ended

reportd drafts a report, keeps its text in memory for the person who asked, and sends exactly that text when it is told which draft to send. The draft named is not kept for you: it is more than 60 minutes old, it was sent or queued already (a draft is dropped once it is queued, so a second send of it ends here), reportd restarted, which forgets every draft, a newer draft of yours pushed it out (it keeps 8 for a person and 64 in all), or the ID is not one of yours. Nothing was sent.

## What to do

1. Draft the report again: choose what went wrong on the Report a problem page, or run `report` at a terminal. Read the new text, which is the one that will be sent.
2. Send it within the hour.
3. If the earlier one was sent, `report list` shows it under the reports from this machine: it needs no second send.
4. If reportd is not running, the page says so: run `elevate service reportd start`.
