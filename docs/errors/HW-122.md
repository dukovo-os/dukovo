# HW-122: A processor gave a wrong answer under load

Each CPU ran the same work for the time of the check: a chain of SHA-256 hashes and a product of floating-point matrices, folded into one number. The work gives the same number on every processor. One of the CPUs gave another number than the first answer, which means that it computed wrongly while it worked hard. The line says which CPU, in which round, and what it gave. A processor that does this cannot be trusted with any work, even when it seems to run well.

## What to do

1. Do not rely on this machine for anything that matters until it is fixed. Back up what matters, and check that the copy is whole.
2. Undo any overclock, undervolt or other change to the clock or the voltage in the firmware, and turn off any boost that is not the default. Most wrong answers come from a setting that is too fast or too low in voltage for the part.
3. Check the power supply and the cooling. A power supply that is too small for the machine or that is failing gives wrong answers under load, and so does a processor that is too hot (see HW-123).
4. Run `elevate hardware check cpu --time 600` to see if it happens again, and on which CPU. If it still fails with default settings, the processor is faulty: replace it.
5. To check that it worked, run the check again and see `every answer agreed`.
