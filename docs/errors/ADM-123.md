# ADM-123: The command did not work

The console ran the command for the action, and the command ended with an error. The detail is the last line the command wrote as an error, and the answer's `command` holds the command's words, its exit status and its error output, which the console shows as "the program's own words".

When the command names its own error ID, such as SVC-104, and the action lists that ID, the answer carries that ID in place of ADM-123, so that its own page explains it.

## What to do

1. Read the program's own words under the message: they say what went wrong.
2. Run the same command at a terminal, as the console shows it, to see the whole of its output.
3. Fix what it names, then try again.
