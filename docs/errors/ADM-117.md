# ADM-117: That method is not used here

The console answers three methods, `GET`, `HEAD` and `POST`, and each route takes one: what only reads is `GET`, and what changes anything is `POST`. This request used another, or the wrong one for its address, such as a `POST` to a page or a `GET` to a route that changes something. The console's own pages always use the right one.

## What to do

1. Reload the page and try again.
2. A script uses the method that the route takes.
