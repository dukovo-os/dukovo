# NET-102: The network card has no link

The card exists, but it senses no other end: the cable is not in, the other end is off, or a virtual machine's virtual cable is unplugged. `netcheck` reads the card's link as the system keeps it, and no layer above the link can work without one, so the layers after it are not checked.

## What to do

1. Check the cable at both ends, and try another cable or another port of the switch or router.
2. Check that the switch or router the cable goes to is on.
3. Run `nic net0` to see what the card says: "Link detected: no" means the card senses nothing.
4. In a virtual machine, check that the hypervisor's network cable or link is connected.
5. Run `netcheck` again: it passes the link layer once the card has a link. A card takes a few seconds to get its link after the cable goes in.
