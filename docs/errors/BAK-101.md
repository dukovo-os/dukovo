# BAK-101: There is no backup place by that name

A `backup` command that works on one place (`show`, `run`, `verify`, `key`, `remove` or `restore`) was given a name that no backup place has. A place is named when it is added with `backup add`, such as `office-nas`, and its settings are in `/system/settings/backup/NAME.toml`. Nothing was changed.

## What to do

1. Run `backup list` to see the places this machine backs up to, with their names.
2. Run the command again with a name from that list.
3. If the place should be there but is not, it was removed, or it was never added on this machine. Add it with `backup add`; the backups that are already at the place are not changed by removing it.

backup(8), backup.toml(5), the handbook's chapter on the web console.
