# ADM-119: The request is not JSON

A request that changes something sends its body as JSON, with the type `application/json`. This one had a body of another type, or of none. Nothing in the console takes a form or plain text.

## What to do

1. A script sends JSON and the header `Content-Type: application/json`.
2. If the console's own page gets this, reload it.

admind(8), ADM-108, ADM-113.
