# BAK-102: A backup round is running

`backup run` was started while a round of backups is running: one started by the timer, by another `backup run`, or from the web console. One round runs at a time, so that two do not write to a place together or read the same files twice. Nothing was changed.

## What to do

1. Wait for the round that runs to end. `backup list` says when each place was last backed up, and the Snapshots page shows the round as a task.
2. Run the command again.
3. A round that was stopped without ending, by a restart or by being killed, leaves its lock behind. The next `backup run` sees that no process holds it and takes it over, so running the command again is enough.

backup(8), the handbook's chapter on the web console.
