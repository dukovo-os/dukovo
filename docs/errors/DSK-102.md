# DSK-102: Every block of this filesystem is being checked

`scrub start` was given a filesystem whose blocks another `scrub` is reading now. A scrub reads every block of a filesystem and checks it against its checksum, which takes hours on a large one, and a second one at the same time would read everything twice and slow both. The scrub that runs may have been started from a terminal, from the web console's Storage page, or by a task. Nothing was changed.

## What to do

1. Wait for the scrub that runs to end. The Storage page shows its progress, and its task drawer says how far it has come.
2. Run the command again after it has ended. The result of the last scrub is kept for each filesystem, and `storage show` and the Storage page say when it was made and what it found.
3. A scrub that was stopped without ending, by a restart or by being killed, leaves its lock behind. The next `scrub start` sees that no process holds it and takes it over, so running the command again is enough.
