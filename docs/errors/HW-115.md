# HW-115: A disk warns that it may fail

A disk's record of its health, as diskhealth reads it, shows a warning: an attribute that tells of age is at or below its threshold, sectors were reallocated, are waiting to be reallocated or could not be read, SMART is off, or an NVMe drive is too hot, has used its rated endurance or has had media errors. Or the counts that come before a failure rose since the `diskhealth` service last looked, or an NVMe drive has used 90% of its endurance. The line names the disk and the reasons. Disks often fail within weeks of these counts starting to rise, and some last for years.

## What to do

1. Make sure that what is on the disk is backed up, and that the backup can be read back.
2. Run `diskhealth DISK` to see the attributes in full. A count that does not move from one check to the next is a disk that had a fault and settled; a count that rises is one that is failing.
3. If SMART is off, turn it on in the firmware. A disk with it off cannot warn of anything.
4. Plan to replace the disk, and run `elevate hardware check disks --full` to read it all and have it test itself at length. If its counts keep rising, replace it soon.
5. To check that it worked, run `diskhealth` for the new disk and see `PASSED`.
