# MET-113: A RAID controller's battery needs replacing

The battery or cache vault of a RAID controller has failed or is missing, which is a critical alert, or is worn or failed its test of its own capacity, which is a warning. The key is `raid-battery:CONTROLLER`. Without a working battery, a volume set to write back writes straight to the disks, which loses nothing but is slower. The alert is cleared when the battery's state is good again.

This is the same fact as the failure of `hardware check raid` (HW-174), told when it happens and not when someone looks.

## What to do

1. Run `storage raid` to see the battery's state, charge and temperature, and whether writes go straight to disk.
2. Replace the battery or the cache vault, as HW-174 says.
3. To check that it worked, wait until the new battery has charged: `storage raid` shows it working normally, and the alert is cleared.
