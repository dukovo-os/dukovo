# HW-102: The memory gave wrong data

The memory controller counted errors that it could not correct, since the machine started (`ue_count` in `/kernel/devices/system/edac/mc/mc0`). A program or the kernel read memory that held the wrong data. What the machine did with it is not known: a file may have been written wrong, and a program may have been given a wrong answer. This is a failure of the memory.

## What to do

1. Back up what matters now, to another disk. Check afterwards that what was saved is whole, since it may have been written from memory that was wrong.
2. Restart the machine and choose *Test the memory* in the start menu, to find which module is at fault.
3. Replace the module. Until it is replaced, the machine can give wrong data again at any time.
4. To check that it worked, run `elevate hardware check memory` after the restart: the memory errors line must say `none counted since the start`. Run `elevate scrub start -B /` and the same for each Btrfs volume under `/volumes`, to find files that were written wrong.
