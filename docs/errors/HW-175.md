# HW-175: A RAID controller reports a fault

The controller's own state is *fault*: its firmware stopped with an error. The line gives the firmware's fault code in hex when it has one. A controller in fault does not serve its volumes; the disks behind it cannot be read or written until it is working again.

## What to do

1. Run `storage raid` and `storage raid events` to see the state and what the controller logged. Note the fault code.
2. Back up what you can from other disks, and restart the machine. A restart resets the controller, and a fault that was a one-off does not come back.
3. If the controller is in fault again, update its firmware to the package the maker gives for the model (`storage raid` shows the model and the package now installed), and check that it is seated and that its heatsink is cool: a controller that overheats may stop.
4. If it still faults, contact the controller's maker with the fault code.
5. To check that it worked, run `elevate hardware check raid` and see the controller pass.
