# DB-102: A database or role of that name is there already

`database add` makes a role and a database of the names it is given, which PostgreSQL keeps apart from each other. PostgreSQL said that one of them exists. A role that `database add` made before it met the failure is dropped again, so nothing is changed.

## What to do

1. Run `elevate database list`: it lists the databases and the roles, and says which `database` made.
2. To use another name, run `database add` with another.
3. If the database is the one you want, use it: `elevate database password NAME` gives its owner a new password, which is shown once, and the old one stops working.
4. To start over with the same name, remove the database first with `elevate database remove NAME --role`. It deletes the database's data, and the role when `database` made it and it owns nothing else.
5. To check that it worked, run `elevate database list`: the database is there once.
