# ADM-108: The request is not right

The console's server could not use the request. The console's own pages do not send such a request, so this is from a script, a browser extension or a proxy that changes what the page sends, or a page loaded before the console changed. The detail says what is wrong:

- the body is not JSON, or is JSON that this route does not take;
- the address is longer than 2 KiB;
- a value is longer than 4096 bytes, or holds a NUL;
- a value is not what the route needs, such as a passkey's answer that is not base64url;
- the body did not arrive whole, or did not arrive in 10 seconds;
- the request brings an API token and a session's cookie both.

## What to do

1. Reload the page, and do it again.
2. Turn off extensions and proxies that change requests, and try once more.
3. For a script: send JSON as the route takes it, and no more than one of a token and a cookie.
4. If the console's own page keeps getting this, report it with the detail, and what `elevate log -s admind` says.
