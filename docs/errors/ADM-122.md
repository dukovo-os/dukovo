# ADM-122: This account can look but not change

The change asked for runs as an administrator, and the account that is signed in is not one. Everyone who may use the console can look at what it shows, and can make the changes their own account is allowed to make; changes to the machine itself are an administrator's. Nothing was changed.

The same answer refuses an unlock to an account that is not an administrator, since an unlock is for those changes, and an API token whose owner is not an administrator when it asks for one.

## What to do

1. Ask an administrator to make the change.
2. If this account should be an administrator's, an administrator makes it one: `elevate user set --admin NAME`. Then unlock the console and make the change.
