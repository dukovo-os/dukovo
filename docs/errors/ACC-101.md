# ACC-101: There is no account by that name

A `user` command, or `passwd`, was given the name of an account that this machine does not have. An account is found by its name, such as `ann`, in the letters it was made with: a name is lower-case, and a different spelling is a different name. Only people's accounts are listed; the accounts that apps and the system run under are not. Nothing was changed.

## What to do

1. Run `user list` to see the accounts the machine has, with their names.
2. Run the command again with a name from that list.
3. If the account should be there, it may have been removed. `user add` makes it again, and its files are in `/users/NAME` if its home was kept.

## See also

user(8), passwd(1), the handbook's chapter on the web console.
