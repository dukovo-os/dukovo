# ADM-112: The session's worker did not answer

Each signed-in session has a worker, `admind --worker`, which asks authd for the person's own second steps, passkeys, recovery codes and tokens as that person. The console asked it something and got no answer in 30 seconds, or an answer that does not read. The detail says which.

## What to do

1. Try again.
2. If it keeps happening, sign out and sign in again, which starts a new worker.
3. Read `elevate log -s admind`, which has the worker's lines, and `elevate log -s authd`.

## See also

admind(8), authd(8), ADM-121, the handbook's chapter on the web console.
