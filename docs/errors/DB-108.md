# DB-108: The firewall's rules cannot take the block for port 5432

`database allow` and `database deny` keep the rules for port 5432 between two comment lines of the firewall's rules, `/system/settings/firewall`: `# database(8): who reaches PostgreSQL from other machines (ADR 0570)` and `# database(8): end`. They write the block whole each time and change no other line. The file cannot take it, for one of two reasons:

- The two lines do not make one block: the start line has no end line, the end line has no start line, the end line comes before the start line, or either line is there twice. `database` does not guess which is right. The words of the error give the line numbers.
- The block would make the file hold more rules than the firewall holds, 128. The words say how many.

Nothing was changed: not `pg_hba.conf`, not PostgreSQL's settings, not the firewall. `database list` shows the same words under its problems.

## What to do

1. For lines that do not make one block, open the file as an administrator, `elevate nano /system/settings/firewall`, and go to the lines the error names. Leave one start line and one end line, in that order, or take out both with the rules between them: the next `database allow` writes the block again.
2. For too many rules, take out the rules you no longer need with `elevate firewall remove NUMBER`; `elevate firewall list` numbers them. A network that many databases share is one rule, so only networks that differ add rules.
3. Run `database allow` or `database deny` again.
4. To check that it worked, run `elevate database list`: it lists no problem.
