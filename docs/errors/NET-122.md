# NET-122: The gateway does not answer

The card has a default route, but the router it names did not answer two echo requests, as `ping` sends them. The message names the router and, when the system said why, the reason, such as "Destination Host Unreachable". Nothing beyond the router can be reached until it answers, so the layers after it are not checked.

## What to do

1. Check that the router at that address is on and plugged into this network. Run `ping` with the address the message names to see it answer or not.
2. Check that the address is the right one: with DHCP, the server gives it, and a second DHCP server on the network, such as a router's own, may give another. Without it, the `router =` setting in /system/settings/network names it, and must be on the network of the card's address.
3. Some routers do not answer pings from their networks but pass what is sent through them. If `netcheck --internet` and `ping` to an address beyond the router work, the router is only silent.
4. Run `netcheck` again: it passes the gateway layer once the router answers.
