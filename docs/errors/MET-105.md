# MET-105: Memory is nearly used up

Less than 5 percent of the memory is available for 5 readings in a row, a minute apart by default. Available memory is what is free plus the page cache, which the kernel gives back when programs need it, so this is memory that programs hold. The message says how much is available out of how much there is. The warning is cleared when 10 percent is available.

A machine that runs out of memory refuses programs that ask for more, or slows to a crawl as it swaps.

## What to do

1. Run `top -o %MEM` to see which programs hold the memory, and `free` to see how it is used, and the swap.
2. Stop or restart what holds too much: `elevate service NAME restart` for a service. `metrics show service.memory --since 1d --every 1h` shows whether a service has grown with time, which points to a leak in it.
3. If the machine is simply too small for what it does, add memory, or stop what it does not need.
