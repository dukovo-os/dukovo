# DB-106: There is no account of that name

`database add --peer ACCOUNT` makes a role named for an account of this server, with no password: the account signs in over PostgreSQL's socket, which tells the server who connects. No account of that name is on this server, so there is nobody for the role to be. Nothing was made.

## What to do

1. Run `user list`: it lists the accounts of the people of this server. Spell the name as it is there.
2. If the account does not exist yet, make it: `elevate user add NAME`.
3. To use a password instead of an account, leave out `--peer`: the database then has a role of its own, with a password shown once.
4. To check that it worked, run `database add` again: it makes the database and its role.

## See also

database(8), user(8), the handbook's chapter on PostgreSQL.
