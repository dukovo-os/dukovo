# SEC-101: A firewall rule lets every port in from everywhere

A rule in `/system/settings/firewall` allows connections to every port, from every address, on every network card and for every program, as `allow`, `allow tcp` or `allow any 1-65535` does. The first rule that matches decides, so it lets in what no service asked to open: a program a person starts, such as a development server or a database run by hand, is then reached from every machine that can reach this one, where the firewall otherwise leaves what a person's program listens on to this machine alone. The line names the rule by its number and its words.

A rule of this kind that comes after a `deny` of everything never matches, and is not warned about.

## What to do

1. Run `firewall list`. It numbers the rules; find the one the line names.
2. Remove it with `elevate firewall remove NUMBER`. The rules after it are numbered again, so run `firewall list` before removing a second one.
3. Open only what has to be reached. A service you turn on opens its own ports with no rule. For anything else, name the port, and the network too if it need not be reached from everywhere: `elevate firewall allow tcp 443`, or `elevate firewall allow tcp 8000-8100 from 192.168.1.0/24`.
4. To check that it worked, run `elevate dukovo-check`: the line for `firewall rules` passes. `firewall` lists what other machines reach.
