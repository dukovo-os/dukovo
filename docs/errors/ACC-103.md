# ACC-103: Dukovo does not take that key

`user key add` was given a line that Dukovo does not take as an SSH public key. Keys are taken as `ssh-keygen` writes them in a `.pub` file: the kind of key, its base64 text and a comment, on one line. Ed25519 and ECDSA keys on the P-256 and P-384 curves are taken. Keys of other kinds, such as RSA and DSA, are not, and neither is a line with options in front of the key (`command=`, `from=`, `restrict`): authd passes such a line over when someone signs in, so adding it would give no way in. Nothing was changed.

## What to do

1. Make a key of a kind that is taken: `ssh-keygen -t ed25519`, and give the line of the file ending in `.pub`, in quotes, as one word.
2. Give the line whole, with no breaks. A line that was cut when it was copied is not a key.
3. To give a key a restriction, do it on the SSH server's side; the file only names who may sign in.
