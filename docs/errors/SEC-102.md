# SEC-102: The firewall service is off

The `firewall` service gives the kernel the rules of `/system/settings/firewall` at each start, and ends once they are loaded. When it is off, stopped, failed or gone, the kernel holds no rules for this start: a rule that closes a port a service opens, or lets a port be reached only from one network, is not in force, and what a service listens on is open to every machine while it runs. The line says whether the service is off or failed.

## What to do

1. Run `service firewall explain`. It says in a sentence why the service is in its state.
2. If it is disabled, run `elevate service firewall enable`.
3. If it failed, `service firewall status` and `log -s firewall` say why. A rule in the file that cannot be read is left out and said so by `elevate firewall load`; correct the line, or remove it.
4. Run `elevate service firewall start`. It loads the rules, as `elevate firewall load` does.
5. To check that it worked, run `firewall`: it says how many rules the kernel holds. Then run `elevate dukovo-check`: the line for `firewall on` passes.
