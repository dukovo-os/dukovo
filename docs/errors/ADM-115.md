# ADM-115: API tokens are not accepted yet

The request came with an `Authorization: Bearer` header holding an API token, which starts with `dkv_`. The console takes none in this release. A token, made by its owner in authd with its name, scopes and end, has no use yet, and the console refuses it before it looks at anything else of the request.

## What to do

1. Sign in with a name and a password, as the console's page does.
2. Do not put a token in a script yet; the API that takes tokens is not part of this release.
