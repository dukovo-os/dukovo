# ADM-115: The API token is not accepted

The request came with `Authorization: Bearer` and a token that starts with `dkv_`, and authd did not take it. The token may be mistyped or cut short, it may have been removed, it may have passed its end date, or its account may be disabled or no longer allowed to use the web console. The detail says which, as far as authd tells.

Each wrong token from an address counts. After 10 in a minute, the console answers ADM-105 to that address until the minute is over, before authd is asked again, and authd itself waits longer after each wrong token for the same account.

## What to do

1. Check that the script sends the whole token, exactly as it was shown when it was made, in one `Authorization: Bearer` header.
2. In the console, open your account's API tokens and check that the token is listed and has not ended.
3. If it is gone or has ended, make a new one with the scopes the script needs, and put it where the script reads it.
4. If your account was disabled, ask an administrator.
