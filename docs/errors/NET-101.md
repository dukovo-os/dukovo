# NET-101: The machine has no network card

`netcheck` found no network card to check: the system set none up, or the one named with `--card` is not there. Nothing can be checked above the link until a card exists, so the layers after it are not checked.

## What to do

1. Run `ip link` to see the cards the system set up. A card is named `net0`, `net1` and on; the loopback `lo` is not one.
2. Run `lspci` and `lsusb` to see the devices the computer has. A network card that is listed there but not by `ip link` has no driver in this system; the handbook's chapter on supported hardware lists the cards that do.
3. In a virtual machine, check that the machine has a network card in the hypervisor's settings.
4. If you named a card with `--card`, check its spelling against `ip link`.
5. Run `netcheck` again: it passes the link layer once a card exists.

## See also

netcheck(8), ip(8), lspci(8), lsusb(8), nic(8), the handbook's chapters "Networking", "Supported hardware" and "Checking the network".
