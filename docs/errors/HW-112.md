# HW-112: A disk's self-test failed

A disk tests itself when asked, and keeps the result in its own log. The test that `hardware check` started, the short one or in a full check the extended one, ended with a failure, and the line gives the first sector it could not read, when the disk says. The disk found the fault itself, away from the cable, the port and the system, so the fault is the disk's.

## What to do

1. Back up what is on the disk now, to another disk. Start with the files that matter most, since the disk may stop answering soon.
2. Replace the disk.
3. To see the disk's log of its tests, run `elevate hardware last --json` and look at the disk's self-test check.
4. To check that it worked, run `elevate hardware check disks` on the new disk: its self-test line must say `passed`.
