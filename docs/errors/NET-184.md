# NET-184: Private access is not set up, or has no such device

`wireguard add` or `wireguard remove` was run on a machine that has no private access yet, or `wireguard remove` named a device that the interface does not have. Private access is the WireGuard interface `wg0`, which `wireguard serve` makes, and a device is a peer of it, named when it was added. Nothing was changed.

## What to do

1. Run `wireguard show` to see whether `wg0` is set up and which devices it has, by name.
2. If it is not set up, run `elevate wireguard serve`, or set it up on the Security page, and add the device again.
3. If the device is not listed, it was removed already, or it was added under another name. Run the command with a name from the list.
