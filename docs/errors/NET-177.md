# NET-177: The firewall's rules are being tried

A change to the firewall's rules was asked while an earlier change to /system/settings/firewall is still being tried. Spark keeps one trial for a file at a time, and undoes it by putting the file back as it was before the trial, so a second change made now would be lost when the first is undone. Nothing was changed.

## What to do

1. Keep the change being tried with `elevate firewall keep`, or undo it with `elevate firewall undo`. The Firewall page shows the same trial with **Keep this change** and **Undo now**.
2. Or wait: Spark undoes the trial when its time runs out, and the page or `service list --json` says when.
3. Make the new change again.
