# ADM-137: This browser comes through what the change takes away

The change would remove the private access that this browser reaches the console through: the device it signed in from. Once it was gone the browser would have no way to ask for anything more, and the change could not be undone from here. Before anything runs, the console compares the browser's connection with the device's addresses, and it refuses too when it cannot read them while the browser is on that interface. Nothing was changed.

## What to do

1. Open the console from another connection, such as this machine's own network or another device, and make the change there.
2. Or, at the machine, run `elevate wireguard remove NAME`.
3. To keep the browser's access and remove a different device, choose that one: removing another device of the same interface is allowed.
