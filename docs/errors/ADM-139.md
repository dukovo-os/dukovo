# ADM-139: That session has ended already

The request named a console session or a terminal that is not there any more. A person ended it, signed out of it, or an administrator did; it ran out its time; or the console restarted, which ends every session and every terminal. Nothing was changed.

## What to do

1. Nothing needs fixing: the list of sessions on the Accounts page, and on Your account, shows what is signed in now. Reload it.
2. If the session you meant to end is gone, it needs no more doing.
3. If a session you did not expect is on the list, end it, and change the password of the account.
