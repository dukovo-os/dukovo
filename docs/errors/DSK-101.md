# DSK-101: There is no such disk

`storage grow` or `diskhealth` was given the name of a disk that this machine does not have. A disk is named as the kernel lists it, such as `sda`, `nvme0n1` or `vda`, and not as a path. `storage grow` takes the whole disk and refuses a partition (`sda1`) with this error too; `diskhealth` refuses a name the kernel does not list at all. A disk that is unplugged, or that the machine did not find at start, is not listed. Nothing was changed.

## What to do

1. Run `storage show` to list the disks the machine has now, with their names. `lsblk` lists them too.
2. Run the command again with a name from that list.
3. If a disk you plugged in is missing from the list, check its cable or port, and run `hardware check` to see whether the machine finds it.

## See also

storage(8), diskhealth(8), lsblk(8), the handbook's chapter on the web console.
