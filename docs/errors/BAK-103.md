# BAK-103: This key does not open these backups

`backup restore` was given a recovery key that does not decrypt the record of these backups. Each place's backups are encrypted with the key that `backup add` made for it, so only that key opens them. The key of another place, one that was typed with a mistake in it, and one of an older set of backups all give this. Nothing was changed.

## What to do

1. Find the recovery key that was shown when the place was added. It is saved in a file named for the place, `NAME.key`, if it was saved, and on this machine, if it is the one that made the backups, in `/system/settings/backup/`.
2. Give the key as it was written, with no spaces added, or give the file that holds it.
3. If the key is lost and the machine that made the backups is gone, the backups cannot be opened: no one else holds a copy of the key.
