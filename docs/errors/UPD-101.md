# UPD-101: An update did not prove itself

An update starts with three tries to pass the health check. It failed them, so the computer went back to the version before it by itself, with the settings it had before the update. The line before this one in the log says what failed, with its own error ID.

## What to do

1. Run `changes --failed` to see what failed and what the update changed.
2. Follow the page of the error ID it names.
3. The computer runs the version before the update; `sysupdate stage` tries again once a newer release is out.

## See also

changes(1), sysupdate(8), the handbook's chapter on updates.
