# ADM-121: The console could not do that

The console's server could not do something it needs for itself, whatever the person asked. The detail says what: it could not make the link to a session's worker, could not get random bytes for a session, could not read the account files to find who is signed in, or met a failure of its own.

## What to do

1. Try again.
2. If it keeps happening, read `elevate log -s admind`, and check the service: `elevate service admind status`.
3. `elevate service admind restart` starts it again. That ends every console session, so everyone signs in again.
4. Report it with the detail and the log lines.

## See also

admind(8), service(8), log(1), ADM-112, the handbook's chapter on the web console.
