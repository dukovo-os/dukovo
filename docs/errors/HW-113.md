# HW-113: A disk has sectors that cannot be read

The read scan of `hardware check` read the disk and some of it could not be read. It reads the disk through its device file: 256 pieces of 4 MiB spread evenly over the disk in a quick check, all of it in a full one. A piece that failed was read again in halves, down to single sectors, so the line names the sectors, as `unreadable sectors: 40000, 70000-70001`: the first ten ranges, and says how many more places there were. The numbers are logical sectors of the disk from its start.

## What to do

1. Back up what is on the disk now, to another disk. A file that has sectors in the ranges cannot be read whole; copy the others first.
2. Replace the disk. A disk that cannot read its sectors will not read them later, and more follow.
3. If the same sectors fail on another cable and port, the disk is the fault. If the failures change from run to run, check the cable and the port first: see HW-114.
4. To check that it worked, run `elevate hardware check disks` on the new disk: its read scan must say `none unreadable, none slow`.
