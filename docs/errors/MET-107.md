# MET-107: A certificate is about to end

A certificate in /system/settings/ssl ends in 14 days or less, or the days that `certificate-days` in metrics.toml says. The message names the file and says the day it ends. The warning is critical when it ends within 3 days or has ended. metricsd reads the first certificate of each .pem and .crt file there once an hour, and skips a file with only a key in it.

Programs that check a certificate refuse one that has ended, so a connection that needs it, such as the log sent to a syslog server over TLS, fails.

## What to do

1. Get a renewed certificate from the authority that issued it, with the same name or names.
2. Copy it over the file the message names in /system/settings/ssl.
3. Have the services that use it read it again, as `service logforward reload` does for logforward.
4. Within an hour the warning is cleared. If it is not, the file the message names is not the one that was replaced: see which ones are in the folder.

A certificate that is no longer used needs no renewal: remove its file, and the warning is cleared.
