# BAK-107: These backups were made by a newer Dukovo

`backup restore --machine` read a record of backups that a later release of Dukovo wrote, in a format that this release does not know. Reading it as if it were older could leave out what the newer one saved, such as settings or hardware it describes, so the restore stops before it stages anything. Nothing was changed.

## What to do

1. Update this machine to the release that made the backups, or a later one. `sysupdate` does it, and the Updates page shows the version.
2. Run the restore again.
3. If this machine cannot be updated, restore on a machine that can, and move the files from there.

## See also

backup(8), sysupdate(8), the handbook's chapter on moving to new hardware.
