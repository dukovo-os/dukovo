# HW-103: The memory test read back a wrong value

A memory test wrote a pattern to part of the free memory and read a different value back. Two tests give this ID.

The memory test of `hardware check` runs while the system does. Its line gives the address of the word, the value it read, the value it wrote, and which pattern it was: the word's own address, a moving inversion of 0x55 and 0xAA, or a random value. Each pattern is read back twice, so a value that changes between two reads shows too.

The memory test at the start, which `hardware memtest --next-start` or the Hardware page asks for, tests all the free memory before the first program. It says in the log and in `hardware memtest --status` how many words read back wrong and in which ranges of addresses, and raises a critical alert. The kernel takes each page that has an error out of use until the next restart, so the system runs, with less memory, and the same pages are found again at the next test.

In both the memory is faulty, or the machine's settings for it are wrong.

## What to do

1. Do not trust this machine's data. Back up what matters, to another disk, and check that the copy is whole.
2. If the memory or the processor was overclocked, or a profile such as XMP or EXPO is on, set the firmware back to its default settings and run the check again. A memory that fails only at the faster setting is not faulty at the speed it is made to run at.
3. Run `hardware memtest --status` to see which ranges of addresses failed in the last test at a start. Choose *Test the memory* in the start menu, which tests all of the memory and says which addresses fail. With several modules, take out all but one and test each in turn; the one that fails is the one to replace.
4. To check that it worked, run `elevate hardware check memory`: the memory test must say it passed. After a replacement, ask for the test at the start with `elevate hardware memtest --next-start`, restart, and read `hardware memtest --status`: the last test must say it passed, and the alert is cleared.
