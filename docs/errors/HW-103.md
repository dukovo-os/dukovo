# HW-103: The memory test read back a wrong value

The memory test of `hardware check` wrote a pattern to part of the free memory and read a different value back. The line gives the address of the word, the value it read, the value it wrote, and which pattern it was: the word's own address, a moving inversion of 0x55 and 0xAA, or a random value. Each pattern is read back twice, so a value that changes between two reads shows too. The memory is faulty, or the machine's settings for it are wrong.

## What to do

1. Do not trust this machine's data. Back up what matters, to another disk, and check that the copy is whole.
2. If the memory or the processor was overclocked, or a profile such as XMP or EXPO is on, set the firmware back to its default settings and run the check again. A memory that fails only at the faster setting is not faulty at the speed it is made to run at.
3. Restart the machine and choose *Test the memory* in the start menu, which tests all of the memory and says which addresses fail. With several modules, take out all but one and test each in turn; the one that fails is the one to replace.
4. To check that it worked, run `elevate hardware check memory`: the memory test must say it passed.
