Common questions

Is Dukovo Linux?

No. Dukovo has its own kernel, Radix, written in Rust. It runs the same shell tools and many of the same programs, and familiar commands such as systemctl and journalctl work.

Will it run on my computer?

Dukovo 1.0 runs on 64-bit x86 PCs and on common virtual machines and clouds. Supported hardware lists what has been tested.

Does Dukovo collect data about me?

No. No telemetry, no accounts, and nothing leaves your computer unless you set it up. This site has no cookies or analytics either. The privacy promise.

How do I get help?

Search here first, then ask in Discussions. Every page has a link to report a problem with it.
