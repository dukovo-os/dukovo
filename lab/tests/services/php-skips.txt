# The tests of PHP's suite that the lab's test services/php leaves out,
# each group with the reason it fails on Dukovo. A line is a test file's
# path from the top of the suite (`ext/standard/tests/file/fgets.phpt`), or
# a folder's, which ends in a slash (`ext/sockets/tests/`): the lab test
# runs the tests of the suite whose paths start with none of them. When
# a gap closes, its lines go: the gaps waiting on work are in
# docs/deferred.md.
#
# The list is made from a run, under emulation, of the tests that ask the
# system for something: those of tests/ and sapi/cli/tests/, of
# ext/standard/tests/ for files, the network, general functions and
# streams, and of the sockets, posix, pcntl, sysvsem, sysvshm, shmop,
# session, openssl, curl and ftp extensions (ADR 0499). Each test that
# failed there, or ran for longer than its time, was read for its reason
# before its line was added. The rest of the suite, the language's own tests
# among them, is for the lab test to run on hardware, which adds a line for
# each that fails there.

# mlibc's getprotobyname(3) and getprotobynumber(3) find no protocol, and
# its getservbyport(3) ignores the protocol it is given (it names "http"
# for UDP port 80 as well).
ext/standard/tests/network/getprotobyname_basic.phpt
ext/standard/tests/network/getprotobynumber_basic.phpt
ext/standard/tests/general_functions/getservbyport_variation1.phpt

# The C library has no res_search(3), so the build has no dns_get_record(),

ext/standard/tests/network/dns_get_record_error_conditions.phpt
